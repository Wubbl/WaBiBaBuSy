## 3. Known limitations (accepted for now)

- **Pattern / Traveling Colors unsupported for video content** (GIF/image only) — roadmap Tier 3.
- **Tearing on mismatched refresh rates (Win11 24H2+)** — Windows compositor limitation; workaround: match refresh rates (the room view warns on mismatch).
- **Remote multi-monitor**: a remote machine renders on one monitor (`target_monitor_index`, default primary).
- **`FaceTravelDirection` is not visible in `exactFrame` stills** (derived from the previous live frame) — check facing with live `probe` captures.
- **IconZone issues from April** (`.docs/2026.04_IconZoneAnimation_TODO.md`) — re-verify each against current code before working on them.
