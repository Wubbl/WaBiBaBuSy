## 3. Known limitations (accepted for now)

- **Background images / multi-image sources are not file-transferred to remotes** — only the primary animation file is distributed. Remote falls back to solid color / drops missing sources with a log warning. Fix = register additional contentIds + client-side download before apply.
- **Pattern/Traveling Colors unsupported for video content** (GIF/image only) — document as non-goal or implement.
- **Tearing on mismatched refresh rates (Win11 24H2+)** — Windows compositor limitation; workaround: match refresh rates (topology UI warns on mismatch).
- **Remote multi-monitor**: a remote machine renders on one monitor (`target_monitor_index`, default primary). Multiple monitors of one remote as separate topology nodes exists only partially.
- **IconZone issues from April** (`.docs/2026.04_IconZoneAnimation_TODO.md`) — some may have been fixed by the late-April commits (dynamic zone size, visual/occupancy padding split); re-verify each item against current code before working on them.
