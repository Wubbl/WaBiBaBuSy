## The Problem

**DXGI swap chain on Windows 11 24H2 is not updating the desktop display.**

After the first `Present()` call shows the first frame, subsequent `Present()` calls do not update what's visible on screen. The swap chain is presenting to the back buffer, but Windows Desktop Window Manager is not compositing those updates to the display.
