## Medium Priority (Post-MVP)

### Video Frame Capture in D2D Mode
**Status:** MVP uses placeholder frames
**What:** Replace placeholder frames in `VideoWallpaperRenderer` with actual LibVLC frame capture for the D2D composition pipeline.
**Why:** Currently videos in D2D mode show colored placeholder rectangles instead of actual video content.
**Files:** `WaBiBaBuSy.WallpaperEngine/Renderers/VideoWallpaperRenderer.cs`

### Auto-Reconnection with Exponential Backoff
**Status:** Partially complete — basic reconnection exists, no backoff strategy
**What:** Implement exponential backoff (1s, 2s, 4s, 8s, max 30s) with connection state management.
**Files:** `WaBiBaBuSy.Core/Services/Networking/WallpaperSyncClient.cs`

### Content Cache Management (LRU Eviction)
**Status:** Partially complete — caching works, no size limits
**What:** Track total cache size, implement LRU eviction, default max 5GB (configurable).
**Files:** New `WaBiBaBuSy.Core/Services/ContentCacheManager.cs`

### Auto-Update UI Integration
**Status:** Core update infrastructure complete, no UI dialogs
**What:** Update notification dialog, progress dialog, settings UI for update preferences.
**Remaining testing:** Failure scenarios, rollback, mandatory vs. optional updates, concurrent multi-client updates.

## Completed Features

All completed feature details are documented in `.docs/RECENT_UPDATES.md` and the git history. Key completed milestones:

- Auto-update system (version detection, chunked download, SHA-256, standalone updater, rollback)
- Distributed animation system (Phases 1-4: distribution, timing sync, sequential/simultaneous, UI)
- Native D2D composition (GPU-resident frames, persistent device context, Magick.NET)
- Separate player process (Windows 11 24H2+ explorer crash fix)
- Gallery multi-select with thumbnails, search, filtering
- Background color auto-detection from edge pixels
- LibVLC pre-initialization (9s → instant startup)
- Video thumbnail generation and caching
- Logging system with UI controls (level, component toggles, file output)
- GIF renderer, image renderer, video renderer
- Drift detection and correction (±50ms)
- Full gRPC protocol (register, heartbeat, sync, transfer, topology, updates)
- mDNS auto-discovery
- Inno Setup installer
