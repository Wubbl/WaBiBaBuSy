## Medium Priority (Post-MVP)

### ~~Video Frame Capture in D2D Mode~~
**Status:** COMPLETE — native D2D video playback implemented in `WaBiBaBuSy.Player.D2D/Program.cs` (LibVLC → raw buffer → `CopyFromMemory` → `ID2D1Bitmap`). The old placeholder path only survives as a pre-first-frame fallback in the legacy `CompositionRenderer` pipeline.

### ~~Auto-Reconnection with Exponential Backoff~~
**Status:** COMPLETE (2026-07-07) — `WallpaperSyncClient` reconnects with 1s..30s exponential backoff on sync-stream loss or 3 consecutive heartbeat failures; `_clientId` is preserved so the server resumes the active animation on re-register. Needs E2E validation (<5s target measured on a real network).

### ~~Content Cache Management (LRU Eviction)~~
**Status:** COMPLETE (2026-03-24) — `ContentCacheManager` enforces `MaxCacheSizeMB` with LRU eviction before downloads. Settings UI already existed.

## Feature-Completeness Roadmap (2026-07 audit)

See **`.docs/2026.07_FEATURE_OVERVIEW.md`** for the full verified feature inventory and prioritized roadmap. Headlines:

- **Tier 1 (reliability):** remote parameter parity (full MovementConfig + backgrounds over gRPC), fix Simultaneous mode on remotes, clock-offset estimation via heartbeat, auto-reconnection + session resume, dead-client sweep, real remote monitor geometry

## Completed Features

All completed feature details are documented in `.docs/RECENT_UPDATES.md` and the git history. Key completed milestones:

- Auto-update system (version detection, chunked download, SHA-256, standalone updater, rollback)
- Distributed animation system (Phases 1-4: distribution, timing sync, sequential/simultaneous, UI)
- Native D2D composition (GPU-resident frames, persistent device context, Magick.NET)
- Separate player process (Windows 11 24H2+ explorer crash fix)
- Gallery multi-select with thumbnails, search, filtering
- Background color auto-detection from edge pixels
- LibVLC pre-initialization (9s → instant startup)
- Video thumbnail generation and caching
- Logging system with UI controls (level, component toggles, file output)
- GIF renderer, image renderer, video renderer
- Drift detection and correction (±50ms)
- Full gRPC protocol (register, heartbeat, sync, transfer, topology, updates)
- mDNS auto-discovery
- Inno Setup installer
- Pause on fullscreen (fullscreen app detection + auto hide/show wallpaper)
- Content cache LRU eviction (enforces MaxCacheSizeMB with least-recently-used eviction)
