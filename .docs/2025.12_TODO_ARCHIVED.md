#### `TASK-000A` Fix "Apply via Direct2D" Behavior - Simple Centered Playback

- **Description:**

  - [ ] No animation movement (stationary playback)
  - [ ] No background layer rendering
  - [ ] Content loops indefinitely on that monitor
  - [ ] Multi-monitor selection works (can apply to multiple monitors simultaneously with same content)
  - [ ] Animation system ONLY triggers when user explicitly uses "Animation" feature

- **Implementation Notes:**
  Need to create two separate code paths:
  1. **Simple Direct2D Playback**: Just render content centered, no composition pipeline
  2. **Animation Mode**: Full composition pipeline with background + movement

- **Time Estimate:** 3-4 hours
- **Blockers:** None

#### `TASK-003` Add SetFrameAsync to D2DPlayerHost
- **Status:** 🔴 Not Started
- **Priority:** P0 (Critical)
- **Assignee:** Dev
- **Dependencies:** TASK-002 (FRAME command must be implemented)
- **Related Files:**
  - `WaBiBaBuSy.WallpaperEngine/Direct2D/D2DPlayerHost.cs:239-249` (near SetColorAsync)
- **Description:**
  Add a method to send composed bitmap frames to the player process via the IPC protocol.

- **Acceptance Criteria:**
  - [ ] `SetFrameAsync(byte[] jpegData)` method added
  - [ ] Sends `FRAME:` command with base64-encoded data
  - [ ] Waits for "READY" or "ERROR:" response
  - [ ] Returns Task for async/await pattern
  - [ ] Handles errors and logs appropriately
  - [ ] Includes XML documentation

- **Implementation:**
  ```csharp
  /// <summary>
  /// Sends a frame to the player process to display.
  /// </summary>
  /// <param name="jpegData">JPEG-encoded frame data</param>
  public async Task SetFrameAsync(byte[] jpegData)
  {
      if (!IsRunning)
      {
          _logger.LogWarning("Cannot send frame: player not running");
          return;
      }

      var base64 = Convert.ToBase64String(jpegData);
      await SendCommandAsync($"FRAME:{base64}");

      // Wait for response
      if (_playerProcess != null)
      {
          var response = await _playerProcess.StandardOutput.ReadLineAsync();
          if (response?.StartsWith("ERROR:") == true)
          {
              _logger.LogError("Player failed to display frame: {Error}", response);
          }
      }
  }
  ```

- **Time Estimate:** 1 hour
- **Blockers:** Requires TASK-002 completion
